¿Qué es Apache Kafka?

Plataforma de streaming de eventos distribuida y de código abierto

Event Streaming

Captura, almacena y procesa flujos de eventos en tiempo real. Un evento es un registro inmutable de algo que ocurrió (ej: una transacción bancaria, un clic, un sensor).

Distributed Commit Log

Almacena eventos de forma secuencial e inmutable en topics particionados y replicados. Diseñado para alta disponibilidad y tolerancia a fallos.

Componentes Fundamentales

Los bloques de construcción de la arquitectura Kafka

Topics

Canales lógicos donde se publican eventos. Similar a una tabla en BD, pero diseñado para streaming. Soportan retención configurable.

Partitions

División horizontal de un topic para paralelismo. Cada partición es un log ordenado e inmutable. Permite escalar horizontalmente el throughput.

Brokers

Servidores Kafka que almacenan datos y sirven clientes. Múltiples brokers forman un cluster. Cada partición tiene un líder y réplicas ISR.

Microservicios & Kafka

Comunicación asíncrona y desacoplada entre servicios

Desacoplamiento

Los productores no conocen a los consumidores. Cada microservicio usa su propia tecnología y escala independientemente.

Resiliencia

Si un servicio cae, los eventos se acumulan en Kafka. Al recuperarse, continúa desde el último offset procesado.

Escalabilidad

Añade más particiones y consumidores para aumentar el throughput. Consumer Groups permiten procesamiento paralelo.

Implementación & Conclusión

De la teoría a la práctica

Ejemplo: Producer Java
// Configuración del Productor Properties props = new Properties(); props.put("bootstrap.servers", "kafka:9092"); props.put("key.serializer", "org.apache.kafka.common.serialization.StringSerializer"); props.put("value.serializer", "io.confluent.kafka.serializers.json.KafkaJsonSchemaSerializer"); props.put("acks", "all"); // Durabilidad total Producer<String, PaymentEvent> producer = new KafkaProducer<>(props); // Enviar evento de pago PaymentEvent event = new PaymentEvent( transactionId, userId, amount, timestamp ); producer.send(new ProducerRecord<>( "fintech.payments.processed", userId, // Key para orden por usuario event ));
Ejemplo: Consumer con Streams
// Kafka Streams: Detección de fraude StreamsBuilder builder = new StreamsBuilder(); KStream<String, Transaction> transactions = builder.stream("fintech.transactions"); transactions .groupByKey() .windowedBy(TimeWindows.of(Duration.ofMinutes(5))) .count() .toStream() .filter((key, count) -> count > 10) // >10 tx en 5min .to("fintech.alerts.fraud", Produced.with( WindowedSerdes.timeWindowedSerdeFrom(String.class), Serdes.Long() )); KafkaStreams streams = new KafkaStreams( builder.build(), config ); streams.start();
